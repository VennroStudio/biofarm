# БИОФАРМ — три полных варианта главной

Открыть сравнение: http://localhost:8769/index.html

1. http://localhost:8769/a.html — «Природная лёгкость»: светлый фон, мягкая зелень, композиция с тремя товарами справа.
2. http://localhost:8769/b.html — «Лес и наука»: контрастный лесной первый экран, лимонные акценты, отдельная композиция типографики и продуктов.
3. http://localhost:8769/c.html — «Живая энергия»: абрикосовый первый экран, терракотовые акценты, цветные категории и выразительная форма.

Каждый вариант — полная страница: шапка → категории → товары → производство → компания → документы → блог → отзывы → маркетплейсы → бонусы → сотрудничество → подвал.

Это самостоятельные HTML/CSS-прототипы для выбора направления. Приложение не изменено. Проверка наполнения — CONTENT-AUDIT.md; происхождение изображений и промпты — IMAGE-PROMPTS.md.

Для повторного запуска:

```sh
python3 -m http.server 8769 --bind 127.0.0.1 --directory /Users/viktor/Projects/myProjects/biofarm/design-previews/biofarm-v10
```

HTML можно открыть и напрямую из этой папки. Для товарных ссылок, поиска и видео требуется работающий сайт проекта на localhost:8088.
