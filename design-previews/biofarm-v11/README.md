# БИОФАРМ — выбранный компактный дизайн в коде

Открыть: http://127.0.0.1:8770/index.html

Полный самостоятельный прототип на HTML/CSS/JavaScript по home-final.png. Приложение БИОФАРМ не изменено.

## Что реализовано

- Общая фотографическая мятная шапка с тремя отдельными товарными переходами.
- Четыре категории и четыре товара с текущими ценами и упаковками из проверенного набора данных v10.
- Фильтры товаров, демонстрационная корзина, поиск по действующему каталогу.
- Широкий блок производства и просмотр существующего видео сайта.
- Компактная лента документов с существующими PDF и пометками «Демо».
- Три действующие статьи; на телефоне горизонтальная прокрутка карточек.
- Пять исходных отзывов без сокращения текста, небольшие фотографии и увеличение фото.
- Два магазина на маркетплейсах без списка преимуществ.
- Действующие условия бонусной программы и сотрудничества.
- Форма: имя, телефон, email и сообщение. Имя, email и сообщение обязательны. Отправка демонстрационная, серверный запрос не выполняется.
- Мобильное меню, адаптивная сетка, состояния фокуса и поддержка prefers-reduced-motion.

## Файлы

- index.html — собранная страница.
- style.css — оформление и адаптивность.
- preview.js — поведение интерфейса.
- build.py — сборка HTML из сохранённых source-*.json.
- assets/hero-background.png и assets/production.png — декоративные фоны, созданные встроенным ImageGen. Промпты: HERO-ASSET-PROMPT.md и ASSET-PROMPT.md.
- Остальные изображения, данные и документы скопированы из v10. Происхождение: ../biofarm-v10/CONTENT-AUDIT.md и ../biofarm-v10/IMAGE-PROMPTS.md. Изолированные упаковки из ImageGen могут отличаться мелким текстом от исходной фотографии; документы в текущей базе демонстрационные.

Пересобрать:

```sh
python3 /Users/viktor/Projects/myProjects/biofarm/design-previews/biofarm-v11/build.py
```

Запустить после остановки предпросмотра:

```sh
python3 -m http.server 8770 --bind 127.0.0.1 --directory /Users/viktor/Projects/myProjects/biofarm/design-previews/biofarm-v11
```

Для поиска, видео и переходов на исходные товарные/информационные страницы нужен сайт проекта на localhost:8088. Основной макет, изображения, документы, отзывы, демонстрационная корзина и форма работают без него.
