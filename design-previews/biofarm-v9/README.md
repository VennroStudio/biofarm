# БИОФАРМ — объединение двух последних референсов

Одна главная страница, показанная крупными последовательными фрагментами.

## Что изменено

- Первый экран: крупный заголовок и свободная композиция с наклонёнными упаковками. У каждого из трёх товаров свой переход; общая кнопка ведёт в каталог.
- Категории: заголовок слева, карточки справа. Светлая палитра и увеличенные интервалы.
- Наполнение: производство, описание компании, документы, статьи, бонусная программа и подробное предложение партнёрам.
- Отзывы: три карточки с текстами, по одному или два небольших фото.
- Маркетплейсы: отдельные карточки Wildberries и Ozon с описанием и своим переходом.
